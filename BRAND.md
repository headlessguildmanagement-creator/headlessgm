# HeadlessGM Brand Foundation

This project uses the supplied HeadlessGM Brand Kit as the visual source of truth.

## Core palette

- Charcoal Navy — `#0B1220`
- Indigo — `#4F46E5`
- Violet — `#A855F7`
- Slate — `#64748B`
- Mist — `#E2E8F0`
- White — `#FFFFFF`

## Typography

- Display / headings: Space Grotesk
- Body / UI: Inter

## Primary messaging

- Run the guild. Not the spreadsheet.
- The system adapts to the guild — not the other way around.
- More than tools. A stronger guild.
- Built around how your guild actually plays.

## Brand qualities

Clear, confident, practical, supportive, flexible, connected, community-focused, reliable and customizable.

## UI direction

- Dark premium application surfaces
- Indigo-to-violet accent gradient
- Restrained borders and soft elevated panels
- Strong Space Grotesk display typography
- Compact, legible Inter UI typography
- Rounded but not playful controls
- Purple accents reserved for emphasis and state
- Product UI should be the primary visual whenever possible

## Imagery guardrail

The supplied brand kit includes fantasy/MMO mountain imagery. Use it as a mood reference and optional campaign treatment, not as the default product identity. HeadlessGM is game-agnostic, so core product pages should rely primarily on interface storytelling, abstract atmosphere, community imagery and non-IP-specific gaming visuals.

## Logo

Use the supplied HeadlessGM logo artwork when final vector/transparent assets are available. Do not redraw, distort or recolor the final mark.
